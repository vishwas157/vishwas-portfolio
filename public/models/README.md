# 3D Model Directory

Place your 3D character GLB model file here:
- **Filename:** `character.glb`
- **Full Path:** `/public/models/character.glb`

## How it works:
1. When you place your `character.glb` file here, the website automatically loads it in full 3D!
2. If the model contains bones/rigging (head, neck, spine), the head and upper body will naturally track the mouse cursor.
3. If it contains animations (e.g., Idle), the website automatically plays the default animation.
4. If no `character.glb` is placed yet, the portfolio automatically displays an interactive glowing 3D Cyber Avatar placeholder core with mouse tracking!
